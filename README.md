# Timberleaf Press — Book Manufacturing Website

A multi-page marketing and operations website for a fictional book manufacturing and printing company. It is a static site deployed on Netlify.

**Stack:** HTML5 · CSS3 · JavaScript · Netlify

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Landing page with services, process and call-to-action |
| `catalog.html` | Product and print catalog |
| `distribution.html` | Distribution and logistics overview |
| `dashboard.html` | Operations dashboard mock-up |

## Run locally

Open `Book Manufacturing Landing/index.html` in a browser, or serve the folder:

```bash
cd "Book Manufacturing Landing"
python -m http.server 8000
```
